# Contributing to plantmaintainance

Thanks for your interest in improving this project.

## Current contribution scope

At this stage, contributions should prioritize:

- documentation clarity,
- safety-boundary language,
- conservative and reversible incremental changes.

## Guardrails (must follow)

- Do not present outputs as definitive diagnosis.
- Do not add medical/agrochemical prescription claims.
- Do not publish or share photo datasets without rights/privacy policy alignment.
- Keep changes minimal and source-grounded.
- Prefer repo-first, docs-first evolution.

## For this phase

Before introducing new functional features (photo upload, case schema, model integrations), ensure related docs and policy files are in place and consistent:

- `docs/vision.md`
- `docs/safety-boundary.md`
- `docs/photo-rights-privacy.md`
- `docs/case-data-handling.md`

## Pull request expectations

Please include:

- what changed,
- why it is safe,
- whether app behavior changed,
- follow-up lane recommendation.

## License note

If a `LICENSE` file is absent, do not assume license terms. Wait for repository owner selection.
