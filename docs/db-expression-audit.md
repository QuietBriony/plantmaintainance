## 3. 監査基準

本監査は次の既存文書を基準に判定しました。

- `docs/safety-boundary.md`
  - 「確定診断ではない」「写真/テキストのみでの断定不可」
  - 「危険木の最終判定不可」
  - 「農薬/除草剤の処方不可（製品名・希釈・時期・方法含む）」
- `docs/photo-rights-privacy.md`
  - 本監査対象のQ&A本文には直接の画像公開導線はないが、将来公開時の誤誘導を避ける観点で過度断定を抑制
- `docs/case-data-handling.md`
  - 観察支援中心、診断確定調の回避
- `docs/sources.md`
  - 断定的主張は根拠文献の裏づけが必要
- `CONTRIBUTING.md`
  - 断定診断・農薬処方の回避、保守的な表現

### 3.1 主な監査観点
- 確定診断に見える断定語（例: 「必ず」「最適」「問題なく」）
- 観察限界（現地確認不足）を無視した判定
- 危険木・構造安全の最終判断に読める表現
- 除草剤・農薬の実質的処方につながる表現
- 根拠出典が必要な強い主張
- 本来は有資格者/管理者/関係当局へのエスカレーションが必要なケースの不足

---

## 4. 重大度ラベル

- **BLOCKER**: DB拡張前または公開相談用途前に修正すべき
- **CAUTION**: 現状Q&Aとしては許容余地があるが、緩和/限定表現が望ましい
- **OK**: 安全境界上の明確な問題なし
- **SOURCE_NEEDED**: 有用だが、拡張前に根拠補強が望ましい

## 6. 推奨リライト方針（次レーン向け）

以下は本レーンでは適用せず、次レーンでの修正方針とする。

- 断定を避け、**「可能性があります」**を基本形にする
- 「診断」ではなく、**観察ポイント**（葉色、葉裏、幹の亀裂、根元のぐらつき等）を提示する
- **「症状の整理」と「診断」を明確に分離**する
- 構造・倒木リスクは、**有資格者（樹木医等）・道路/施設管理者**への相談を推奨する
- 農薬/除草剤は、**法令・ラベル・自治体ルール・有資格者確認**を前提化する
- **製品名・用量・希釈倍率・散布時期/方法**の個別推奨は行わない
- **「必ず」「断定」「これで治る」「安全です」**等の過信表現を避ける
