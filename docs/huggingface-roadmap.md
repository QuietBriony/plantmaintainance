# Hugging Face Roadmap (Deferred)

Hugging Face usage is intentionally deferred during docs-first stabilization.

## Current decision

Ignore integration for now.

## Possible later phases

1. Spaces demo (UI/prototype only) after local policy/docs maturity.
2. Datasets usage only after rights/privacy and consent processes are enforceable.
3. Model experiments only after sufficient safe, policy-compliant structured data exists.

## Preconditions

- Safety boundary finalized.
- Photo rights/privacy policy operationalized.
- Case data handling policy operationalized.
- Contributor expectations documented and visible.

## Constraint reminder

Even in future phases, outputs must remain non-diagnostic and non-prescriptive.
