# Photo Rights & Privacy (Pre-publication Policy)

This project does **not** publish a photo dataset at this stage.

## Current status

- No photo upload feature is implemented.
- No photo dataset publication is active.

## Policy prerequisites before any photo publication

Before enabling contribution/publication, define and enforce:

1. Rights confirmation by contributor (ownership or explicit permission).
2. Consent language covering storage and intended use.
3. Privacy review process (remove personal/sensitive identifiers).
4. Takedown/removal procedure.
5. Jurisdiction-aware handling for minors/private property concerns.

## Minimum contributor declarations (future)

Contributors should attest that they:

- own the images or have permission,
- understand intended usage,
- did not include sensitive personal information intentionally.

## Moderation expectation

Any future photo workflow should include pre-publication moderation and reversible publication controls.
