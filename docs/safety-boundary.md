# Safety Boundary

This repository is intended for observation support and consultation preparation.

## What this project is

- A guidance and triage-support helper.
- A way to organize observations before consulting qualified professionals.

## What this project is not

- Not a definitive diagnosis tool.
- Not a substitute for certified arborist / tree specialist judgment.
- Not a medical advice system.
- Not an agrochemical or pesticide prescription tool.

## Required communication style

Any user-facing guidance should:

- use non-diagnostic phrasing,
- communicate uncertainty clearly,
- recommend escalation to qualified professionals when risk is high,
- avoid overclaiming certainty from limited observation.

## Escalation intent

Future triage flows should explicitly direct users to professional inspection for:

- potential structural/safety hazards,
- high-value or protected trees,
- rapidly worsening conditions,
- suspected regulated pest/disease concerns.
