# Vision

## Short-term identity

`plantmaintainance` is currently a static plant maintenance / Q&A helper.

## Target direction

Evolve conservatively into a **Pocket Tree Doctor companion** focused on:

- tree consultation light,
- structured observation support,
- future photo-case contribution workflows.

## Product stance

The tool should support users in observation and triage preparation, while clearly avoiding definitive diagnosis claims.

## Evolution principles

- docs-first,
- minimal diff,
- keep existing app stable,
- avoid premature AI/vendor coupling,
- separate policy readiness from feature rollout.
